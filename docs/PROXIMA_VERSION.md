# Diseño de la siguiente versión

La idea es evolucionar la herramienta a un generador de plantillas:

1. El usuario selecciona una plantilla.
2. La web muestra únicamente los campos permitidos.
3. Los textos se cambian desde formularios.
4. Las fotos se cambian desde botones de carga.
5. Los objetos inteligentes mantienen la posición, escala y efectos de la plantilla.
6. Se puede generar una copia PSD y/o PNG.
7. Se puede generar una serie de folios automáticamente.

Para plantillas de producción, el mejor enfoque es definir una convención de nombres y editar directamente las capas que correspondan.
