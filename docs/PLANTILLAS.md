# Cómo preparar tus PSD

Para que la herramienta sea fácil de usar, recomiendo preparar las plantillas con nombres consistentes.

## Texto

Usa nombres como:

- `TXT_NOMBRE`
- `TXT_FOLIO`
- `TXT_FECHA`
- `TXT_DIRECCION`
- `TXT_PRECIO`

No rasterices esos textos.

## Imágenes

Usa nombres como:

- `IMG_FOTO`
- `IMG_PRODUCTO`
- `IMG_LOGO`

Idealmente conviértelos en Objetos Inteligentes.

## Estructura recomendada

```text
PLANTILLA
├── FONDO
├── DECORACION
├── IMG_FOTO
├── IMG_LOGO
├── TXT_NOMBRE
├── TXT_FOLIO
└── TXT_FECHA
```

El prefijo no es obligatorio para la versión actual, pero hace mucho más sencillo crear una interfaz personalizada en la siguiente versión.
